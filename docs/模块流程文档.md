# ImageTool（Raw 查看工具）逆向复刻 — 软件模块流程文档

> 目标程序：`ImageTool0_360R.exe`（SHA-256 `a2bf68f71f87…8323`，PE32 x86，1,314,816 字节）
> 复刻产物：本仓库 `ImageTool-Qt`（C 语言核心 + Qt Widgets 界面壳）
> 逆向方法：PE 导入表/资源树静态解析（自研脚本）+ Ghidra 12.1.4 全量反编译（4658 个函数）+ 字符串/交叉引用追踪

## 2. 原程序模块划分（逆向还原）

```
ImageTool0_360R.exe
├─ M1  应用框架层        MFC MDI：CMainFrame/CChildFrame/CDemoDoc/CDemoView
├─ M2  通用图像编解码层  CxImage（BMP/JPG/PNG/TIF/GIF/TGA/PCX/WMF/J2K/PGX/PNM…）
├─ M3  RAW 加载层        .raw/.byr 16bit、.dat 10bit ASCII、.sraw；位深/尺寸/字节序可配
├─ M4  Bayer 解码层      PAT_SEL 排列选择 → 单通道 16bit 平面 → 显示用 RGB
├─ M5  ISP 仿真流水线    ~200 个命名参数（INI 节 ISP_P1）驱动的逐级处理
├─ M6  统计分析层        直方图 / Mean / Std / SNR / RGB Average / CIE1931 / Vector Scope
├─ M7  视图交互层        缩放、像素取色（Bayer_%s of %s / RGBA 显示）、BW/Undo
└─ M8  参数持久化层      INI 节读写 + 注册表（OPEN_DIR/JpegQuality）
```

### 2.2 ISP 参数表（节选自 0x40f2d0，复刻版全部 INI 键见附录 `docs/isp_params_键表.md`）

> 解读说明：反编译显示注册调用形如 `(对象偏移, 类型, "参数名", "ISP_P1")`，
> 第二实参是**数据类型**（0=int / 1=short / 2=float），非默认值。
> 复刻版统一增益为定点：CISGAIN 用 Q5（32=×1.0，对应 0x405b60 的 /32），
> WB 与二级增益用 Q8（256=×1.0），默认取恒等 ×1.0。

| 偏移 | 参数名 | 语义 | 类型 |
|---|---|---|---|
| 0xd9c | PreprocessTh | 预处理阈值 | float |
| 0xda0 | PAT_SEL | Bayer 排列（4 种） | int |
| 0xda4 | DCLP_ON | 数字钳位使能 | int |
| 0xda8/0xdac | DCLP_STRT_H/V | 钳位起始行/列（跳过 dummy 区） | int/short |
| 0xdae | POFFSET | 全局像素偏移(黑电平) | short |
| 0xdb0-0xdb6 | CISGAIN_GR/GB/R/B | 各通道 CIS 数字增益（Q5，除数 32） | short |
| 0xdb8-0xdbe | POFFSET_GR/GB/R/B | 各通道黑电平偏移 | short |
| 0xdc0 | BPR_ON | 坏点校正使能 | int |
| 0xdc4-0xdd0 | BPR_TH1/3/5/7 | 3×3/5×5/7×7 阈值 | int |
| 0xdd4-0xddc | GRGB_ON/GRB/AVG | 绿通道不平衡校正 | int |
| 0xde0 | GTHR01 | GRGB 阈值 | int |
| 0xe98/0xe9c/0xea0 | RGB_FILTER_ON / RGB_GMEDIAN_ON | RGB 前置滤波 | int |
| 0xea4-0xeac | SIG01_CONST/SIG01_MULT/SIG02_MULT | 滤波 Sigma 参数 | int |
| 0xeb0-0xeb8 | PRE/POST_THR_CONT/MULT | 前/后阈值 | int |
| 0xef4-0xf06 | gain_r/g/b_2nd, offset_r/g/b_2nd | 二级增益/偏移（RGB 输出级，复刻用 Q8） | int |
| 0x1074 | GAM_SEL | Gamma 选择 | int |
| 0x10a0- | RGM10~RGM32 | 3×3 颜色矩阵系数 | int |
| 0x10d0- | Mean/Std/Max/Min/SNR 区 | 统计结果存放区 | — |

对话框 ↔ 参数对应：DIALOG 176 Digital Clamp（DCLP_*）、DIALOG 181 White Balance（CRWB/CGWB/CBWB + CRDS/CGDS/CBDS）、DIALOG 182 Raw Format（位深 8~16/H/V size/HL-LH）、DIALOG 184 Y Generation（RY/GY/BY_COEF）、DIALOG 103 Matrix（颜色矩阵 3×3）、DIALOG 178 Analysis（R/Gr/B/Gb 通道 + Snr + ListView）。

## 3. 复刻软件的模块流程

### 3.1 总体数据流

```
                    ┌─────────────────────────────────────────────────┐
 .raw/.byr/.dat ──► │ M3 raw_loader                                    │
 (8/10/16bit)       │  位深展开 → u16 单通道平面 (W×H, 0..1023/65535)   │
                    └───────────────┬─────────────────────────────────┘
                                    ▼
                    ┌─────────────────────────────────────────────────┐
                    │ M5 isp_pipeline（逐级，均 16bit 平面进出）         │
                    │  1 stage_dclamp  钳位+CIS增益 (dummy/有效分区)     │
                    │  2 stage_wb      白平衡 1ch（R/Gr/Gb/B 增益）      │
                    │  3 stage_shading 径向/分窗 Shading 校正            │
                    │  4 stage_bpr     坏点校正 (半径 1/3/5/7 级联确认)   │
                    │  5 stage_grgb    绿不平衡 NR (GRGB/AVG/GRB)        │
                    │  6 bayer_demosaic Bayer→RGB888 (最近邻/双线性)     │
                    │  6a stage_gmedian/stage_prefilter                   │
                    │                  RGB 前置滤波（GMEDIAN/Sigma）      │
                    │  7 stage_gain2nd RGB 二级增益/偏移                 │
                    │  8 stage_matrix  3×3 颜色矩阵                      │
                    │  9 stage_gamma   Gamma (GAM_SEL/gamma_value)       │
                    │ 10 it_y_from_rgb Y = (RY·R+GY·G+BY·B) 系数生成      │
                    │  （原 COLOR_CORRECT 语义由矩阵+Gamma 覆盖，见 §3.4） │
                    └──────┬───────────────────────────┬──────────────┘
                           ▼                           ▼
                    ┌──────────────┐          ┌──────────────────────┐
                    │ M6 analysis  │          │ M4/M7 输出            │
                    │ 直方图/统计/  │          │ QImage 显示/缩放/取色  │
                    │ SNR/CSV 导出 │          │ BMP/PPM/RAW 保存      │
                    └──────────────┘          └──────────────────────┘
```

### 3.2 各模块接口契约（无死参数原则）

所有核心模块为**纯 C**（`src/core/*.h` 声明、`*.c` 实现），不依赖 Qt；GUI 壳（`src/gui/*`）只做事件与展示。每个公开函数的每个参数在实现中都被消费；无未用形参、无占位分支。

| 模块 | 头文件 | 关键 API |
|---|---|---|
| 类型与配置 | `core/itypes.h` | `ItImage`(16bit 平面，含 `full_scale` 量程字段 255/1023/65535——各级钳位与阈值随量程换算)、`ItRgb`(8bit RGB)、`ItConfig`(全部 ISP 参数)、错误码 |
| RAW 加载 | `core/raw_loader.h` | `it_raw_load(path,&fmt,&img)` — 自动探测已知分辨率（含 dummy 行版本），支持 8/10/16bit、ASCII .dat、HL/LH 字节序 |
| Bayer | `core/bayer.h` | `it_bayer_demosaic(img,pat,method,&rgb)` — RGGB/GRBG/GBRG/BGGR × 最近邻/双线性 |
| ISP 流水线 | `core/isp_pipeline.h` | `it_isp_run(&img,&cfg,dump)` — 11 级顺序处理；`it_config_default(&cfg)` 提供恒等默认值 |
| 统计分析 | `core/analysis.h` | `it_stat_compute(img,mask,&stat)`；`it_stat_write_summary(file,&stat)`（复刻 hist_summary.txt 格式）；SNR=Mean/Std |
| 参数持久化 | `core/it_persist.h` | `it_config_save_ini(&cfg,path)` / `it_config_load_ini(path,&cfg,&unknown)` — 复刻原 INI 节 `ISP_P1`，键名用原参数符号名 |
| 图像 IO | `core/imgio.h` | BMP24/PPM(P2/P3/P6) 写出；PPM 用于复刻阶段调试转储 |
| Qt 壳 | `gui/*.h` | MainWindow（缩放视图/取色状态栏/菜单）、RawFormatDialog、IspPanelDialog、AnalysisDialog |

### 3.3 与原程序的对应关系（行为级复刻）

1. **打开 RAW**：GUI 弹出 RawFormatDialog（对应 DIALOG 182：位深/宽/高/字节序）→ `raw_loader` 生成 16bit 平面 → 状态栏显示 `Width x Height : %d x %d`（0x4362a0 同款格式）。
2. **ISP 运行**：IspPanelDialog 五个 Tab 对应原 DIALOG 176/181/190/184/103 的参数 → `it_isp_run` 逐级执行；勾选"调试转储"时按原序输出 `00_d_clamp_out.ppm` … `12_shade_y.bmp`（0x40d110 行为）。
3. **分析**：AnalysisDialog 直方图 + `Mean/Std/SNR/Max/Min` 表格，`Save Summary` 生成与原程序同格式的 `hist_summary.txt`；SNR 定义 = Mean/Std（0x4338b0 同款）。
4. **取色**：视图上显示 `Bayer_%s of %s` 位置与 `RGBA: (%d, %d, %d, %d)`（0x421850 同款格式）。

### 3.4 有意的差异（复刻边界）

| 原程序 | 复刻版 | 原因 |
|---|---|---|
| MFC42 MDI 多文档 | 单文档 + 标签页 | 现代化简化，核心算法不受影响 |
| CxImage 全格式 | Qt QImage（BMP/JPG/PNG/TIF/GIF 内建）+ 自实现 BMP/PPM/RAW | 避免捆绑三方库源码 |
| Excel OLE 导出 | CSV 导出 | 去掉 COM 依赖 |
| TWAIN 采集 | 移除 | 采样硬件相关，无调试价值 |
| 10bit ASCII MessageBox 询问 | 对话框中显式选择 | 消除阻塞式交互 |
